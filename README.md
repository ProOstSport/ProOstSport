# Hallo, ich bin Mike 👋

39 Jahre jung und ein Berliner Umschüler zum **IT-Systemelektroniker**. In meinem Homelab baue ich ein segmentiertes Netzwerk, betreibe einen Linux-Homeserver mit Docker und entwickle eine Backup-Strategie. Ziel ist, die Technik praktisch zu verstehen und sauber zu dokumentieren.

## 📐 Arbeitsweise

- Jedes Projekt ist dokumentiert: Ziel, Aufbau, Konfiguration, Tests, Fehler und Lessons Learned.
- Offene Punkte stehen ausdrücklich in der Dokumentation, nicht verborgen.
- Passwörter und Zugangsdaten gehören nie ins Repository.
- Vor größeren Änderungen gibt es ein Backup. Entscheidend ist, dass sich Sicherungen auch wiederherstellen lassen.
